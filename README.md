## 🛠️ Current Projects

### 1. AWS Resource Tracker

A Bash script that uses the AWS CLI to list AWS resources such as:

* S3 Buckets
* EC2 Instances
* Lambda Functions
* IAM Users

**Location:** `AWS/aws_resource_tracker.sh`

---

### 2. GitHub Access Audit

A Bash script that uses the GitHub API to retrieve repository collaborators and identify users with repository access.

**Technologies used:**

* Bash
* GitHub REST API
* cURL
* jq

**Location:** `Projects/github-access-audit/github_access.sh`
